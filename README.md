# pair-wise-yf-45 影视剧组拍摄通告与资源冲突编排

源提示词摘要：为剧组制片、导演、演员统筹和场记提供通告编排工作台，维护场次、演员档期、场地与器材占用，自动发现资源冲突，支持拖拽排序、状态流转、版本快照、撤销恢复和离线草稿。

## 字段级排期账

场次、演员、场地、器材与版本快照接入同一本字段级排期账（`src/ledger/engine.ts` 纯函数引擎 + `src/stores/schedule.ts` 编排）：

- **字段级版本**：每个场次字段（拍摄日/开始/结束/场地/演员/器材/状态…）独立记版本号、岗位与落地操作；账本条目包含基础版本、字段与岗位。
- **离线按字段合并**：断网时场记的改动按字段记入离线草稿（保留基础版本与最早基础版），回网后逐字段合并——正式侧没动的字段直接合入；两边都改同一字段或同一时段（日/始/末为一组）就留两版，等制片在「排期账 → 撞单裁决」里点选哪版落账。整份草稿覆盖正式通告的路径已移除。
- **改期**：先释放旧占用，再按候选日期顺序落位；共用资源（演员/器材/场地）的未确认场次跟随顺延；场地容量排满就排队候补并写明卡点（哪个场地、容量几、被谁占）；已开拍（拍摄中）场次保留原占用，资源与时段写入一律被拒。
- **失效重算**：资源或时段一变（纪元推进），旧豁免按资源指纹立即失效、冲突重算；候补等未确认排期即时重算——占用一空出自动转正落账，否则刷新卡点。
- **写入纪律**：两人同时提交先写入的生效，后到的留两版待裁决；写队列按到达顺序落地，注入故障后只重试未落地项；所有操作按 opId 幂等，重复回传不新增记录。容量由账本占用推导，晚到的容量回执顶不掉已确认场次。

## 目录

- `src/ledger/engine.ts` — 合并/改期/候补/失效重算纯函数引擎
- `src/stores/schedule.ts` — Pinia 编排：待发队列、故障注入、并发模拟、草稿、裁决
- `src/views/LedgerView.vue` — 排期账页：撞单裁决、待写入口、场地候补、字段账本
- `scripts/verify-engine.ts` — 21 项引擎行为校验（`npm run verify`）

## 技术栈

Vue3、TypeScript、Vite、Element Plus、Pinia、Vue Router、Axios、VueUse、VeeValidate、Zod、Vue I18n、Day.js。
